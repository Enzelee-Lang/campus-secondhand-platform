REST 接口列表（核心）

POST/api/auth/register  用户注册
POST/api/auth/login     登录（用户/管理员）
GET/api/users           用户列表
GET/api/users/{id}     用户详情
PUT/api/users/{id}     修改个人信息
GET/api/items           商品列表（支持分类/关键词过滤）
GET/api/items/{id}     商品详情（浏览量+1）
POST/api/items         发布商品
PUT/api/items/{id}     修改商品
DEL/api/items/{id}     删除商品
GET/api/categories    分类列表
POST/api/reviews      发表评价
POST/api/favorites    添加收藏
POST/api/messages    发送站内消息

REST 接口列表（管理端）

GET/api/admin/stats    运营数据概览
GET/api/admin/users   全部用户
PUT/api/admin/users/{id}/status  禁用/启用用户
GET/api/admin/items   全部商品
PUT/api/admin/items/{id}/off  下架商品
GET/api/reviews/target/{uid}  用户收到的评价
GET/api/reviews/item/{id}    商品评价
PUT/api/reviews/{id}/reply    卖家回复
GET/api/messages/inbox/{uid}  收件箱
GET/api/messages/unread/{uid}  未读数量
POST/api/reports       提交举报
GET/api/reports?status=  举报列表
PUT/api/reports/{id}/handle  处理举报
GET/swagger-ui/index.html  接口文档（Swagger UI）
